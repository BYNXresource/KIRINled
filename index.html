Bandwidth & Performance Warning / 性能与带宽警告

EN: Due to the limited I2C bandwidth of the Control Hub, sending commands to KIRIN may temporarily cause other I2C devices to become unresponsive. Please do not adjust lights frequently within active loops.

ZH: 由于 Control Hub 带宽有限，频繁发送指令会导致其他 I2C 设备（如 IMU）掉线。请绝对避免在 while 循环中不加限制地连续写入灯光指令。

Compliance Notice / 比赛合规提示

EN: Ensure your light patterns comply with the FTC Game Manual to avoid fouls.

ZH: 赛场上请确保您的光效（亮度、频闪率）符合当前赛季的 FTC 手册规定，以免引发意外犯规。

public void setWaveMode(char id, int color1, int color2, int speed) {
    // Seamless I2C Command Generation
    String cmd = String.format(Locale.US, 
        "%c ENTW %s %s %d%% %d",
        id, colorToHex(color1), colorToHex(color2), speed, brightness
    );
    sendCommand(cmd);
}
