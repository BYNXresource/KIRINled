CRITICAL: I2C Bandwidth Blocking Warning / I2C总线阻塞警告

EN: Due to the limited I2C bandwidth of the Control Hub, continuous calls to the module within active loops (e.g., inside `while(opModeIsActive())`) will saturate the bus. This causes IMU and sensor data retrieval to lag, leading to loss of robot control or odometry drift. Send light commands ONLY when the robot's state changes.

ZH: 由于 Control Hub 带宽受限，在主循环中不加节制地高频调用灯光指令，会导致 I2C 总线彻底拥堵，致使 IMU 及其他传感器数据掉线，直接引发底盘失控或自动阶段坐标偏移。请务必使用状态机，仅在“状态发生切换时”发送一次灯光指令。

Compliance Notice / 比赛合规提示

EN: Ensure your light patterns comply with the FTC Game Manual to avoid fouls (e.g., extremely bright strobes that distract drivers).

ZH: 赛场上请确保您的光效符合当前赛季的 FTC 手册规定（避免使用过亮或可能干扰对手视觉的爆闪），以免引发意外犯规。
