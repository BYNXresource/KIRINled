Zero Overhead Principle / 零开销原则

EN: V3 firmware handles all animations (Breath, Waves, Fading) autonomously via STM32 DMA. Send the command ONCE and let the module render it. Do NOT spam I2C commands in loops.

ZH: V3 固件由单片机 DMA 全权接管亚像素级动画渲染。只需触发一次指令，即可实现渐变与流水。严禁在循环中频繁发送指令干扰定位算法。

STM32LedModule.java
// 1. V3 Breath Engine: Global breath across 3 colors with easing=1.5
led.setBreathMode(true, 100, 1.5, 100, Color.RED, Color.ORANGE, Color.YELLOW);

// 2. V3 Anti-Aliased Stripe: Seamless blend moving Right
// Width: 3.0, Gap: 1.0, Anti-Alias: true, Easing: 2.0
led.setAdvancedStripeWave(3.0, 1.0, Direction.RIGHT, true, 2.0, 80, 100, 
    Color.RED, Color.YELLOW, Color.GREEN);

// 3. V3 Auto Progress Bar: Laser Blast
// Fill over 1.0s (Accel=2.0) -> Hold 0.2s -> Erase Right (FB) over 0.5s
led.triggerAutoProgressBar(Color.CYAN, Color.BLACK, 
    1.0, 2.0, FadeType.DIRECTIONAL_ERASE, 0.2, 0.5, Direction.RIGHT, 100);
